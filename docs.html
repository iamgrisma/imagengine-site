Universal URL Syntax & Transforms

ImageEngine routes, optimizes, and edge-caches any asset on-the-fly using a clean, path-based hierarchical URL pattern.

1. Universal URL Format

Every asset request follows the multi-tenant namespaced schema: 

https://img.grisma.info.np/{tenant_id}/{subdomain}/{path/to/asset}.webp
{tenant_id}
The verified organization identifier mapped to your root domain (e.g. acme).
{subdomain}
The specific app or microservice (e.g. store, blog, app). Automatically resolved without manual code changes.
{path}
Relative resource path at your origin (e.g. products/sneaker-white, media/banner).
.webp
Target extension. Supports .webp (recommended), .png, or .jpg.

3. Query Parameters Reference

Parameter Type Default Description
w integer original / 1200 Target width in pixels. Height is scaled proportionally unless h is specified.
h integer auto Target height in pixels.
avatar boolean false Enables face-aware smart square cropping (defaults to 256x256 WebP).
format string webp Output image format. Values: webp, png, jpg.

4. Edge Cache Headers

Every optimized asset response contains immutable caching directives honored by modern browsers and Cloudflare's 330+ edge data centers: 

Cache-Control: public, max-age=31536000, s-maxage=31536000, immutable
CDN-Cache-Control: public, max-age=31536000, immutable
CF-Cache-Status: HIT
X-Render-Engine: sharp-raster (or sharp-svg)
